# Project RAT roadmap

This roadmap keeps the growing TP Mechanical ribbon organized. Each item should be developed on its own feature branch and merged into `main` only after it builds and is tested in Revit 2026.

## Active foundation

- [x] TP Mechanical Revit ribbon application
- [x] Drawing QA/QC command foundation
- [x] Hanger Placement window and rule models
- [x] Fabrication catalog and selection services
- [x] Hanger placement planning and validation services
- [x] Git and two-developer collaboration setup

## Next

- [ ] Complete multi-hanger spacing and end-offset workflow
- [ ] Add collision detection and controlled hanger shifting
- [ ] Add structural attachment selection and validation
- [ ] Add Trimble/layout-point placement and export
- [ ] Expand drawing QA/QC checks and results reporting

## Later

- [ ] Add connector and fabrication-system validation tools
- [ ] Add shared company standards and configuration
- [ ] Add repeatable release packaging and installation
- [ ] Add automated build checks for pull requests

## Feature rule

One roadmap item equals one focused branch and one pull request whenever practical. This keeps reviews small and makes problems easy to isolate or reverse.
